# 命令速查

## 安装

一行安装会检查并按需安装 git、uv、FFmpeg，验证或克隆官方仓库，同步依赖、安装 Chromium、安装 `huayang` 命令并运行安装自检。检测到 Codex CLI 时还会自动安装 Huayang Plugin：

```powershell
iwr -useb https://raw.githubusercontent.com/guigu856/huayang/main/install.ps1 | iex
```

```bash
curl -fsSL https://raw.githubusercontent.com/guigu856/huayang/main/install.sh | bash
```

手动安装：

```powershell
uv sync --extra dev
uv run playwright install chromium
uv tool install --force --editable .
huayang doctor
```

系统需提供 `ffmpeg` 与 `ffprobe`。安装脚本会尝试自动安装，并在缺失时终止，而不是报告不完整的成功状态。

## Huayang 剪辑创作 Plugin

安装或刷新 Codex Plugin：

```powershell
huayang plugin install codex
```

只构建 Marketplace、不修改 Codex 配置：

```powershell
huayang plugin install codex --build-only
```

命令从源码树或已安装分发包自动定位 `.mcp.json`、Rules、Skills 与 Schemas，不依赖当前工作目录。重复注册已有 Marketplace 或 Plugin 时按幂等安装处理。

检查安装状态：

```powershell
huayang doctor
huayang doctor --json
huayang doctor --skip-browser
```

启动后台管理界面并自动打开浏览器：

```powershell
huayang
```

后台默认监听 `http://127.0.0.1:8788`，可查看和维护 Rules、Skills，查看创作产物、学习产物、工作流任务与 Artifact。

后台保存的上下文由 MCP 立即读取。Codex 原生 Skills 使用 Marketplace 安装快照；修改后重新执行 `huayang plugin install codex`，并新建 Codex 任务刷新宿主上下文。

启动 stdio MCP Server：

```powershell
huayang-mcp
```

Codex Marketplace 包与 Claude Code 项目插件使用同一份 `.mcp.json` 启动命令。校验 Claude Code Plugin 清单：

```powershell
claude plugin validate .
```

指定 Plugin 状态目录和可读取的外部媒体根目录：

```powershell
$env:HUAYANG_OUTPUT_ROOT = "D:\huayang-output"
$env:HUAYANG_MEDIA_ROOTS = "D:\media;E:\shared-media"
$env:HUAYANG_ADMIN_PORT = "8788"
huayang-mcp
```

需要指定源码或独立资源目录时，分别设置 `HUAYANG_PROJECT_ROOT` 与 `HUAYANG_RESOURCE_ROOT`。MCP 客户端进入任务后先读取 `huayang://catalog`，再调用 `workflow_create_task` 和 `workflow_get_stage_envelope`。所有阶段工具使用 Envelope 返回的 `stage_access_handle`。完整流程见 [`组件/剪辑创作插件.md`](组件/剪辑创作插件.md)。

## 本地视频剪辑器

启动浏览器工作台：

```powershell
uv run video-editor serve --host 127.0.0.1 --port 8765
```

创建、读取工程：

```powershell
uv run video-editor project create --name "短片工程"
uv run video-editor project list
uv run video-editor project show PROJECT_ID
```

执行声明式命令批次：

```powershell
uv run video-editor command apply PROJECT_ID --file command-batch.json
Get-Content -Raw -Encoding utf8 command-batch.json | uv run video-editor command apply PROJECT_ID
```

动态轨道命令批次示例：

```json
{
  "expected_revision": 0,
  "commands": [
    {"type": "track.add", "media_domain": "visual", "name": "主画面"},
    {"type": "track.add", "media_domain": "visual", "name": "画中画", "index": 0},
    {"type": "track.add", "media_domain": "audio", "name": "配乐"}
  ]
}
```

从响应读取 `track_id` 后，可提交 `{"type":"track.update","track_id":"TRACK_ID","changes":{"name":"标题层"}}`、`{"type":"track.move","track_id":"TRACK_ID","to_index":1}` 或 `{"type":"track.delete","track_id":"TRACK_ID"}`。工程协议为 `schema_version: "2.0"`；轨道只区分 `visual` 与 `audio` 处理域，第一条 visual 轨是最高视觉层，audio 轨位置不参与视觉层级。片段使用 `kind: "media"` 或 `kind: "text"` 描述内容。

导入素材并导出指定工程版本：

```powershell
uv run video-editor asset import PROJECT_ID D:\media\source.mp4 --expected-revision REVISION
uv run video-editor render PROJECT_ID --expected-revision REVISION --output D:\exports\final.mp4
```

通过 `--root D:\video-projects` 指定工程目录；该全局参数写在子命令前。完整命令与 JSON 契约见 [`组件/本地视频剪辑器.md`](组件/本地视频剪辑器.md)。

## 下载视频

分享文本和纯链接使用同一入口：

```powershell
uv run video-download "<视频链接或平台分享文本>"
```

指定输出目录：

```powershell
uv run video-download "<视频链接>" --output-dir output/download
```

指定 Cookie、代理或浏览器 CDP：

```powershell
uv run video-download "<视频链接>" --cookies cookies.txt
uv run video-download "<视频链接>" --proxy http://127.0.0.1:7890
uv run video-download "<抖音链接>" --browser-cdp http://127.0.0.1:9222
```

下载命令的标准输出为单行 JSON，进度写入标准错误；`--help` 输出命令帮助。成功输出：

```json
{"ok": true, "platform": "Douyin", "file_path": "D:\\project\\video_create\\output\\download\\...mp4"}
```

失败时命令以非零状态退出，标准输出仍可直接解析：

```json
{"ok": false, "error": {"code": "url_not_found", "message": "..."}}
```

## 发布参考学习 Fixture

将四个 tracked 参考报告通过冻结门禁发布到指定 Plugin 输出目录：

```powershell
uv run python validation/reference_publication.py `
  --revision REVISION `
  --project-root D:\project\video_create-plugin `
  --plugin-output-root D:\project\video_create-plugin\output\plugin `
  --source-media-root C:\path\to\reference-videos
```

命令会逐个校验参考视频源文件和报告证据文件的 SHA-256，使用 `audit_only` 确认，
要求报告主 Artifact 以哈希证据清单为父级，校验同源只有一个 active Publication、
上一 active 版本已标记为 `superseded`，并验证阶段一、二、三均能召回新版本。运行清单写入
`<plugin-output-root>/validation/reference_publication/revision_<revision>/run_manifest.json`，
同目录的 `run_manifest.sha256` 保存清单 SHA-256。

## 获取素材

读取已配置来源：

```powershell
uv run material-acquisition sources
```

搜索候选：

```powershell
uv run material-acquisition search "city night" --limit 3
uv run material-acquisition search "vintage cereal commercial" --source archive_org --limit 1
```

获取一个候选：

```powershell
uv run material-acquisition acquire "<candidate_ref>"
```

指定输出根目录时，搜索和获取使用同一参数：

```powershell
uv run material-acquisition search "city night" --output-dir output/materials
uv run material-acquisition acquire "<candidate_ref>" --output-dir output/materials
```

素材命令的标准输出为单行 JSON，进度写入标准错误；`--help` 输出命令帮助。下载文件位于 `output/materials/downloads/`，溯源记录位于 `output/materials/provenance/`。
