# 视频下载组件

## 职责

组件接收纯视频 URL 或包含 URL 的平台分享文本，下载一个视频到本地，并返回结构化结果。

- 通用平台使用 `yt-dlp` 获取元数据和媒体。
- 抖音使用 Playwright 打开视频页，拦截详情接口，校验作品 ID 后通过 `httpx` 下载媒体流。
- Bilibili 请求附带浏览器 User-Agent 与 Referer。
- 播放列表不在组件职责内。
- 组件不生成 AI 内容摘要，不提取字幕，不承诺平台返回的播放地址无水印。

只下载用户有权访问和保存的内容，并遵守平台条款与版权要求。

## 运行要求

- Python 3.11+
- FFmpeg 和 ffprobe 位于 `PATH`
- `yt-dlp>=2026.6.9`
- `playwright>=1.60`
- `httpx>=0.27`
- 抖音下载需安装 Playwright Chromium：`uv run playwright install chromium`

每个下载结果在命名前由 ffprobe 确认至少包含一路视频流。

## Python API

```python
from pathlib import Path

from components.video_download import DownloadConfig, download_video

result = download_video(
    "https://v.douyin.com/example/",
    DownloadConfig(output_dir=Path("output/download")),
    on_progress=print,
)
print(result.file_path)
```

`DownloadConfig` 可设置 `output_dir`、`cookies_path`、`proxy` 和 `browser_cdp`。`on_progress` 是可选的 `Callable[[str], None]`，用于接收中文进度文本。`download_video` 是同步接口；异步 Agent 应通过线程调用，命令行入口已经隔离了这一边界。

## 返回契约

`DownloadResult` 包含以下字段：

| 字段 | 含义 |
| :-- | :-- |
| `platform` | 平台或 yt-dlp extractor 名称 |
| `source_url` | 从输入中抽取出的 URL |
| `canonical_url` | 平台规范视频 URL |
| `video_id` | 平台视频 ID |
| `summary` | 用于命名的标题或描述清洗结果 |
| `timestamp` | 文件名中的 `YYYYMMDD_HHMMSS` 时间戳 |
| `timestamp_source` | `published_at` 或 `downloaded_at` |
| `title` | 平台返回的原始标题或描述 |
| `author` | 平台作者；未知时为 `None` |
| `duration_seconds` | 视频秒数；未知时为 `None` |
| `file_path` | 下载视频的绝对路径 |

## 输出和命名

默认目录为 `output/download/`。文件名固定为：

```text
{YYYYMMDD_HHMMSS}_{summary}_{video_id}.{ext}
```

`summary` 取平台 `title` 或 `desc`，清除 Windows 文件名非法字符并限制为 64 个字符。时间戳统一使用 UTC，优先取平台发布时间；平台不返回发布时间时使用下载时间，并在 `timestamp_source` 标记为 `downloaded_at`。同名文件使用 `_2`、`_3` 后缀，不覆盖已有文件。

## 配置

CLI 参数优先于同名环境变量。

| CLI 参数 | 环境变量 | 含义 |
| :-- | :-- | :-- |
| `--cookies` | `VIDEO_DOWNLOADER_COOKIES_PATH` | 供 yt-dlp 使用的 Netscape 格式 Cookie 文件 |
| `--proxy` | `VIDEO_DOWNLOADER_PROXY` | 下载和浏览器请求代理 |
| `--browser-cdp` | `VIDEO_DOWNLOADER_BROWSER_CDP` | 已运行 Chrome 的 CDP 地址 |

抖音可能要求由浏览器生成的新鲜 Cookie。匿名 Chromium 被风控时，启动带远程调试端口且能正常访问目标视频的 Chrome，再通过 CDP 地址复用该浏览器会话；Netscape Cookie 文件不注入抖音浏览器链路。

## 错误

`VideoDownloadError.code` 是供 Agent 判断的稳定错误码。CLI 执行下载时，标准输出只有一个 JSON 对象，进度写入标准错误；`--help` 输出命令帮助。失败时以非零状态退出并输出：

```json
{"ok": false, "error": {"code": "cookie_required", "message": "..."}}
```

常见错误码包括 `invalid_arguments`、`url_not_found`、`output_unavailable`、`dependency_missing`、`cookie_required`、`douyin_access_blocked`、`download_failed` 和 `invalid_video`。
