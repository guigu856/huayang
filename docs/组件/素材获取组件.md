# 素材获取组件

## 职责

素材获取组件按关键词搜索外部素材库，通过搜索产生的候选引用获取一个视频，并保存来源与授权记录。

Agent 接口固定为：

```text
sources -> search -> acquire
```

- `sources` 返回配置层可尝试的来源，不执行远端健康检查。
- `search` 只返回绑定完整候选记录的 `candidate_ref` 和公开候选信息，不返回下载地址或私有搜索记录路径。
- `acquire` 只接受对应搜索记录中的 `candidate_ref`。
- 获取成功前使用 ffprobe 确认文件包含视频流。
- 获取成功后保存 SHA-256、媒体参数、查询词、来源页面、作者和授权记录。

Agent 接口当前只支持视频素材，不负责音频素材、画面语义检查、素材选定、剪辑规划或任意 URL 下载。用户提供的平台链接由视频下载组件处理。

## 运行要求

- Python 3.11+
- FFmpeg 和 ffprobe 位于 `PATH`
- `httpx>=0.27`
- `pydantic>=2.9`
- 使用 Pond5 低层适配器时安装 Playwright Chromium

## 命令行接口

读取配置层可尝试的来源：

```powershell
uv run material-acquisition sources
```

搜索最多 3 个候选：

```powershell
uv run material-acquisition search "city night" --limit 3
```

指定来源和过滤条件：

```powershell
uv run material-acquisition search "vintage cereal commercial" `
  --source archive_org `
  --limit 1 `
  --min-duration 5 `
  --orientation landscape
```

获取搜索结果中的一个候选：

```powershell
uv run material-acquisition acquire "<candidate_ref>"
```

`search` 和 `acquire` 必须使用相同的 `--output-dir`。命令成功和失败时均向标准输出写一个 JSON 对象；搜索、下载进度写入标准错误；`--help` 输出命令帮助。

## Python API

```python
import asyncio

from components.material_acquisition import MaterialAcquisitionService


async def main() -> None:
    service = MaterialAcquisitionService()
    search = await service.search("vintage cereal commercial", limit=1)
    if not search.candidates:
        return
    result = await service.acquire(search.candidates[0].candidate_ref)
    print(result.file_path)


asyncio.run(main())
```

`MaterialAcquisitionService` 是包根目录公开的 Agent 调用边界。`StockEngine` 和各来源适配器位于具体低层模块，保留多源搜索、下载与可选缩略图能力，不属于 Agent 公共 API；Agent 不直接调用 `StockEngine.search_and_download`。

## 来源

Agent 默认来源链为 Pexels、Pixabay 和 Archive.org。未配置 API Key 的来源不会进入搜索；Archive.org 无需 Key，但缺少明确授权字段的候选不会向 Agent 公开。

| 来源 | 配置 | Agent 默认链 |
| :-- | :-- | :-- |
| Pexels | `PEXELS_API_KEY` | 是 |
| Pixabay | `PIXABAY_API_KEY` | 是 |
| Archive.org | 无 | 是 |
| Coverr | `COVERR_API_KEY` | 否，低层适配器需单独验证 |
| Unsplash | `UNSPLASH_ACCESS_KEY` | 否，低层适配器需单独验证 |
| Mixkit | 无 | 否，低层适配器需单独验证 |
| Videvo | `VIDEVO_API_KEY` | 否，低层适配器需单独验证 |
| Pond5 Public Domain | `POND5_DATADOME_COOKIE` 或 `MATERIAL_ACQUISITION_BROWSER_CDP` | 否，低层适配器需单独验证 |

低层适配器不计入 Agent 可用来源；来源接口、下载字段和逐素材授权记录均需在接入方环境完成实时契约验证。缺少逐素材授权字段时，适配器记录 `unknown`，Agent 授权门禁会拒绝该候选。

候选中的 `license` 是来源接口返回的条目字段，或适配器记录的来源使用规则，不等于逐项法律核验。使用素材前仍需按项目发布地区、用途和来源页面确认权利。

## 输出

默认输出根目录为 `output/materials/`：

```text
output/materials/
  searches/search_<token>.json
  downloads/<provider>_<provider_asset_id>.<ext>
  provenance/<provider>_<provider_asset_id>.json
```

搜索记录包含获取阶段所需的私有候选信息。`candidate_ref` 绑定查询词和完整候选载荷，记录被修改后引用失效。重复获取同一素材时追加数字后缀，不覆盖已有文件。下载先写入输出根目录下的独立临时目录，通过 ffprobe 后再移动到 `downloads/`；失败时临时目录自动清理。

组件把当前本地用户及其可写工作区视为可信边界。引用校验用于发现搜索记录被修改，不用于隔离能够同时修改组件源码和运行状态的进程。

溯源记录包含：

- 本地绝对路径、文件大小和 SHA-256；
- `candidate_ref`、搜索令牌、素材源、源站素材 ID 和来源页面；
- 作者、授权记录和原始搜索词；
- 时长、分辨率、视频编码和音频编码；
- UTC 获取时间。

## 错误

`MaterialAcquisitionError.code` 是供 Agent 判断的稳定错误码。常见错误码包括：

- `invalid_arguments`
- `invalid_query`
- `invalid_limit`
- `material_source_unavailable`
- `material_search_failed`
- `candidate_ref_invalid`
- `candidate_ref_expired`
- `material_rights_evidence_missing`
- `material_download_failed`
- `dependency_missing`
- `invalid_media`
- `output_unavailable`

CLI 失败时以非零状态退出并输出：

```json
{"ok": false, "error": {"code": "candidate_ref_invalid", "message": "..."}}
```
