# BGM 来源依据

## 已接入来源

组件接入 Mixkit Free Stock Music。选择依据是该来源具备公开音乐目录、无需 API Key 的单曲下载入口，以及独立的音乐授权页和用户条款页。这里记录的是来源页面在 2026-07-22 展示的事实，不把来源声明等同于具体作品的发布判断，也不声称 Mixkit 是使用量最高的平台。

| 依据 | 官方页面 |
| --- | --- |
| 音乐目录 | <https://mixkit.co/free-stock-music/> |
| 各素材类型授权入口 | <https://mixkit.co/license/> |
| Stock Music Free License | <https://mixkit.co/license/#musicFree> |
| 用户条款 | <https://mixkit.co/terms/> |

## 页面事实记录

音乐目录当前说明：目录中的音乐可免费下载；无需署名或注册；列举的使用场景包含 YouTube、博客、音乐视频、网站、社交媒体、播客与在线广告；同页也列出 CD、DVD、电子游戏、电视及广播用途的限制。

Stock Music Free License 弹窗当前说明：商业及非商业项目均在其列举范围内；允许在网络或社交媒体平台上的视频点播、播客和广告中下载、复制、修改、分发及公开表演音乐素材；同页列出 CD、DVD、电子游戏、电视或广播、音乐再混音或纯音乐轨、据为己有及登记到权利管理服务等限制。授权入口明确要求按素材类型确认适用授权。

用户条款页面标注最近修订日期为 2025-10-02。条款当前说明：下载获得的是非独占许可而非所有权；使用同时受适用的 Mixkit License 和用户条款等文件约束；不得用脚本或机器人批量下载素材库；某些素材组成部分可能涉及第三方权利；条款可能更新。

## 组件执行边界

组件只执行“单次关键词搜索 → 返回不含下载地址的候选引用 → 取得一个已选候选”，搜索上限为 20，不遍历或批量镜像素材库。取得时重新核对来源页中的素材 ID、标题、作者、时长和下载确认页，再验证下载主机、音频流、时长和 SHA256。

溯源记录保存来源页、授权弹窗与条款页的地址及取得时的内容哈希。`rights_record.scope` 固定为 `provider_page_record_not_publishability_determination`，表示它是来源声明记录；具体项目仍按发布平台、地区、用途、作品组成和取得时间复核。
