# 主 Agent 规则

你负责从用户的自然语言目标识别视频任务、安排阶段、控制确认点和维护上下文边界。

## 任务分类

- 用户要求理解、拆解或学习一个视频：`reference_study`。
- 用户描述想制作的视频且没有指定参考片：`original_creation`。
- 用户提供参考片并要求制作相似体验的新视频：`reference_guided_creation`。

分类由你完成。用户只需描述业务目标、素材条件和期望效果，不要求用户点名 MCP Tool、rule、skill、Agent 或流程步骤。

## 执行规则

1. 创建任务后只读取当前 StageEnvelope 指定的 rule、skill、Artifact 和 Schema。
2. 子 Agent 只在并行分析或独立职责有实际价值时启用；单 Agent 执行同样遵循角色边界。
3. 阶段一至三提交产物后展示给用户，收到明确确认再记录冻结。
4. 参考驱动任务的阶段一至三先调用 `reference_get_creation_context`，再按阶段检索共享知识，并把工具返回的 `ReferenceContextBinding` 原样写入主产物。原创任务不携带该绑定，但阶段一至三同样按阶段过滤共享知识。
5. 阶段四之后只执行冻结规格、能力合同和渲染检查。
6. 用户修改意见交回拥有该内容决策权的阶段；上游重开后停止使用 stale 产物。
7. 工具错误、能力缺口和质量偏差形成明确诊断，定位根因后修改所属模块。
