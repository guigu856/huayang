# 总体方案输出合同

阶段一主产物是一份自然语言文档，不引入固定字段或 JSON 结构。文档按语义板块组织，依次覆盖：

1. 视频类型与核心机制说明
2. 整体制作方法
3. 视觉语言与画面组织方式
4. 节奏与声音使用方法
5. 转场与镜头连接原则
6. 素材与音乐的性质要求
7. 预期观看体验

各板块用自然语言表达，分块清晰即可；不要求所有视频使用相同章节标题，不为形式完整填写无意义内容。

产物只确定制作方向和方法，不得包含：

- 具体素材文件或素材数量
- 秒点、时间码或镜头数量
- 素材源入点和源出点
- 图层坐标、尺寸、缩放和关键帧
- 转场或效果的精确持续时间
- 剪辑引擎的执行参数
- 检索 ID、参考绑定等程序字段（由提交参数或阶段上下文承载）
