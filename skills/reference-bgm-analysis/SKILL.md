# 参考 BGM 分析

1. 核对源音轨、采样率、声道、时长和 `audio_scope`。
2. 查看波形、RMS、频谱通量、瞬态、静音和 tempo 候选。
3. 将音乐划分为引入、蓄力、推进、高潮、缓冲和收尾。
4. 复核基础拍、重拍、弱拍、切分和连续密集节拍组。
5. 根据听感和证据判断鼓、贝斯、旋律、人声、SFX 与新音色事件。
6. 保留半拍、原拍和双倍拍候选，结合画面动作选择实际剪辑节奏层。
7. 输出时间范围、整数微秒、证据、置信度和可剪辑提示。
