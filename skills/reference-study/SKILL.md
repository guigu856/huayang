# 参考视频学习

## 工作单元

1. 归一参考源并确认完整解码、哈希、音视频流和真实时基。
2. 生成逐帧视觉信号、PCM 音频信号、候选边界、证据帧和联系表。
3. 对快切、复杂图层、闪白和低场景分数区间进行密集复核。
4. 加载画面分析、BGM 分析和音画关系资源，形成逐镜与镜头组结论。
5. 归纳可迁移剪辑句子，区分原片专属内容。
6. 生成总体报告、BGM 数据、参考片逐镜表、剪辑规律和阶段投影。
7. 检查主镜覆盖、镜内事件重叠、证据引用、事实等级和依赖闭包。
8. 展示报告，收到用户确认后冻结并发布知识。

自动场景分数、关键帧和节拍只作为候选证据，不直接代替语义结论。
