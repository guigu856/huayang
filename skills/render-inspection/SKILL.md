# 成片检查

1. 检查输出文件、编码、画幅、帧率、音视频时长和完整解码。
2. 检查黑帧、冻结帧、卡顿、破损、响度、削波和异常静音。
3. 按 `action_id` 抽取关键时间帧，核对素材、切换、PIP、空间和时序是否按规格渲染。
4. 检查是否真实使用不同素材，素材内容与主题是否一致。
5. 检查镜头密度、卡点、图层协调、画面呼吸和视觉冲击是否达到总体方案。
6. 将问题定位到素材、规格、编译器、渲染器或检查器所属边界，并给出可复现证据。
