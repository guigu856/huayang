# 参考画面分析

1. 先通览低频联系表，建立整体视觉段落。
2. 查看候选边界前后帧和逐帧信号，判断主画面真实更换。
3. 把 PIP、字幕、局部特效、遮罩和布局变化记录为镜内事件。
4. 对连续高分变化聚类，区分闪白、动作模糊、转场和硬切。
5. 在低全屏变化区检查局部区域、角色动作、字幕和背景变化。
6. 为每个镜头记录主次图层、位置、尺度、遮挡、运动、效果作用域和连接。
7. 把连续镜头归入 `rhythm_unit_id`，同时保留证据与置信度。
